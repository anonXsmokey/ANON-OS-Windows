# External Reference Ingestion Policy

ANON OS Windows draws technical lessons from public Windows optimization and gaming projects, including projects supplied by the founder. External material is research input, not an instruction to copy implementation or branding.

## Newly supplied references

### Community configuration reference
- https://gist.github.com/clowieth215-crypto/b57a486dcd0779f577d3c0d47abc4f28
- Status: research-only until content, provenance, license, and safety are independently reviewed.

### Ghost Spectre
- https://ghostspectre.the-ninja.jp/19H2.X64.html
- Relevance: study lightweight Windows distributions, component-removal philosophy, optional feature sets, deployment workflow, and hardware-oriented trade-offs.
- Status: research-only. No files, trademarks, proprietary binaries, or unclear modifications are to be incorporated without a separate legal and technical review.

## Research rules

For every external project we study, record:

1. what problem it solves,
2. what is technically interesting,
3. what can be independently reimplemented,
4. what has a license compatible with ANON redistribution,
5. what may be risky or obsolete,
6. what should explicitly not be copied.

## ANON standard

ANON OS Windows should outperform reference projects through better measurement, safer version-awareness, stronger recovery, more automation, better gaming lifecycle management, and a more coherent user experience—not through indiscriminate removal of Windows components.
