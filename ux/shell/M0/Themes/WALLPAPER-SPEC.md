# ANON Wallpaper System

Wallpapers are part of the product identity, not incidental decoration.

## Built-in sets

- `anon-core` — signature ANON dark atmosphere; restrained purple energy.
- `aurora` — soft blue/violet atmospheric lighting; premium and calm.
- `carbon` — near-black technical texture; optimized for gaming setups.
- `pulse` — dark magenta/pink energy; expressive theme companion.
- `light` — bright neutral surface with subtle ANON geometry.
- `crimson` — dark red accent atmosphere; high-impact gaming variant.

## Asset rules

- Minimum delivery: 3840x2160 for 4K desktop displays.
- Provide 16:9 masters and safe crops for 16:10 and ultrawide displays.
- Avoid text baked into wallpapers so UI localization remains clean.
- Keep focal content away from the normal icon/taskbar safe areas.
- Maintain dark/light luminance targets so desktop text remains readable.
- Do not ship third-party copyrighted artwork without an explicit redistribution license.

## Runtime modes

`static`, `slideshow`, `theme-linked`, and future `dynamic` modes are supported by the product specification.

## Naming

Use lowercase stable IDs for runtime references. Human-readable names belong in the theme catalog, not in filenames used as identifiers.
